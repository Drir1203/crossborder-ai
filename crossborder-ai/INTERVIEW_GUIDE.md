## 一、如何回答 Agent 技术问题

### 面试官问："里面有没有用到好的 Agent？"

**推荐回答：**

> "我的平台用了 **ReAct（Reasoning + Acting）模式** 的 Agent，基于 DeepSeek 的 **Function Calling** 能力。
>
> 核心循环是：**模型思考 → 决定调用哪个工具 → 执行工具拿到结果 → 把结果反馈给模型 → 模型根据结果决定下一步**，直到任务完成。
>
> 我注册了 9 个业务工具（品类分析、选品、单品决策、1688抓取、Listing生成、合规修复、利润计算、整店巡检等），模型能自主组合这些工具完成复杂的跨境决策任务。"

### 面试官追问："为什么不用扣子（Coze）/ Dify？"

**推荐回答：**

> "我调研过扣子（Coze）、Dify、Flowise 这些 Agent 平台。它们的核心能力是：
> - **可视化工作流**：拖拽节点搭建流程
> - **插件生态**：海量工具即插即用
> - **知识库（RAG）**：文档检索增强
> - **多 Agent 编排**：任务拆解给多个 Agent
>
> 但我们选择了**自研 Agent**，原因是：
> 1. 我们的工具是**垂直业务工具**（1688 数据、合规审查、利润计算），扣子没有这些插件，都得自己接
> 2. 自研能**深度集成**到我们的产品流程（用户体系、积分、套餐限制）
> 3. 扣子的多 Agent 编排对我们当前的业务量**过度设计**——9 个工具用一个 ReAct Agent 就够了
>
> 但扣子的 **知识库增强** 和 **可视化工作流** 是我们未来可以借鉴的方向。"

### 面试官追问："ReAct 和 Plan-and-Execute 有什么区别？你用了哪种？"

**推荐回答：**

> "两种都是多步任务处理方式：
> - **Plan-and-Execute**：先让模型制定完整计划，再按步骤执行。适合**流程可预测**的任务（如：先抓取→再生成→再发布）。
> - **ReAct**：模型**边思考边行动**，每一步都基于上一步的结果决定下一步。适合**需要动态决策**的任务（如：先分析市场，根据结果决定选什么品）。
>
> 我的平台**两者都用了**：
> - 预设工作流（1688→Shopify 上架）用 Plan-and-Execute，稳定可控
> - 自由指令（"这个品能不能做"）用 ReAct，灵活决策
> - 如果 ReAct 失败，自动降级到 Plan-and-Execute，保证稳定性"

## 二、如何回答商业化问题

### 面试官说："当前平台商业化并不是很好"

**推荐回答：**

> "我认同，这也是我在思考的方向。当前平台的问题在于**定位偏窄**（Listing 生成），商业化天花板有限。
>
> 我已经在做两件事调整：
> 1. **重新定位**：从 'AI 生成 Listing' → 'AI 帮你做跨境决策'，聚焦选品决策这个更高价值的环节
> 2. **覆盖全链路**：选品 → 单品判断 → Listing 生成 → 合规修复 → 上架 → 整店巡检，形成闭环
>
> 但我清楚这个方向的**天花板**（中小卖家工具，月费 ¥99-249，目标月入几万），它不是能拿大融资的项目，更适合做成**小而美**或**被收购**。如果要做大，需要转向供应链优化、跨境支付等更大市场。"

### 面试官追问："和店小秘、领星比，你的优势在哪？"

**推荐回答：**

> "店小秘、领星是**全链路 ERP**（订单、库存、财务），我是**垂直 AI 工具**（决策 + 内容生成），不是直接竞争。
>
> 卖家的流程是：**选品 → 上架（我们）→ 订单/库存/财务（店小秘/领星）**。
>
> 我的差异化：
> - **AI 决策深度**：16 语言翻译对照、合规自动修复、利润自动计算，这些是店小秘/领星没有的
> - **产品体验**：完整 Web UI + 微信小程序，不是 CLI 工具
> - **定位清晰**：不做全链路，专注上架环节做到极致"

## 三、Agent 技术栈总结

| 组件 | 实现 |
|------|------|
| 模型 | DeepSeek V4 (Function Calling 支持) |
| 模式 | ReAct（推理循环）+ Plan-and-Execute（预设工作流） |
| 工具 | 9 个注册工具，模型自主选择 |
| 对话记忆 | 数据库持久化（Conversation 表） |
| 工作流 | 6 个预设模板 |
| 降级策略 | ReAct 失败 → Plan-and-Execute |

## 四、9 个注册工具

1. `analyze_category` — 品类市场分析
2. `select_products` — 选品推荐
3. `analyze_product_decision` — 单品决策
4. `scrape_1688` — 1688 抓取
5. `generate_listing` — Listing 生成
6. `compliance_check` — 合规检查
7. `compliance_fix` — 合规自动修复
8. `calculate_profit` — 利润计算
9. `store_check` — 整店巡检
