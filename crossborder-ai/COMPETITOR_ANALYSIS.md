## 二、差异化优势（VeyaShip 独有的）

| 功能 | 说明 |
|------|------|
| **1688 + 自有货源双模式** | 其他项目要么只做 1688，要么只做自有商品 |
| **合规审查** | 正则 + AI 双层检测违禁词，竞品都没有 |
| **利润计算器** | 输入售价成本自动算净利 |
| **翻译对照** | 原文 vs 译文并排显示，质量可查验 |
| **完整的 Web UI** | 竞品多是 CLI/MCP/Skill，没有完整的前端 |

## 四、建议下一步方向

根据竞品对比，建议按以下优先级推进：

### 第一阶段（立即做）
1. **Amazon 一键发布** — 对标 DSers，接入 Amazon SP-API
2. **关键词研究** — 接入 Amazon 广告 API，提供搜索量和竞争度数据

### 第二阶段（1-2 周）
3. **选品推荐** — AI 分析 1688 热销品类
4. **多店铺切换** — 一个账号绑定多个店铺

### 第三阶段（长期）
5. **Amazon 订单管理** — 订单同步、库存同步
6. **A+ 内容生成** — 带图片的商品详情页
7. **数据分析看板** — 销售趋势、利润分析

---

## 五、总结

**VeyaShip 当前的核心竞争力：**
1688 抓取 + AI Listing + 合规 + 利润计算 + Shopify 发布的**完整闭环**，且全部有 Web UI。

**最大的短板：**
只支持 Shopify 发布，不支持 Amazon/eBay 等核心平台。
