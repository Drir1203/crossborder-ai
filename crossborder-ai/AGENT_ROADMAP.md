## 三、整店巡检闭环（5.0 首个落地闭环）

> 5.0 定时 Agent 的第一步：把"整店巡检"从 Agent 手动触发升级为「定时 + 手动 + 看板展示」的完整闭环。

### 触发方式

| 方式 | 说明 | 触发点 |
|------|------|--------|
| ⏰ 定时巡检 | 每天凌晨 2:30 自动检查**所有用户**的商品 | Scheduler `_run_store_checks`（store_check_daily） |
| 👆 手动巡检 | 看板点「立即巡检」，检查**当前用户**商品 | `POST /api/v1/analytics/store-check`（扣 1 积分） |
| 🤖 Agent 巡检 | 对话里说"检查一下我的店铺" | Agent 的 store_check 工具 / 整店巡检工作流 |

### 检查项与数据

- **检查项**：缺标题 / 缺价格 / 缺链接，命中任一即标记"需处理"
- **存储**：`store_check_logs` 表（每次巡检一条，问题商品存 JSON）
- **查询**：`GET /api/v1/analytics/store-check-history`（最近 20 条倒序）

### 看板展示

看板「整店巡检」区块：最近巡检摘要（总数/正常/需处理）→ 问题商品列表 → 历史记录 → 「立即巡检」按钮。

## 四、未来路线图（4.0+）

| 版本 | 方向 | 说明 | 优先级 |
|------|------|------|--------|
| 4.0 | 知识库 RAG | 接入平台规则、跨境法规、类目知识库，增强回答准确性 | ⭐⭐⭐ |
| 4.1 | 多模型路由 | 简单任务用小模型省钱，复杂任务用大模型 | ⭐⭐ |
| 4.2 | 自我反思 | 生成结果后自我审查，质量不过关自动重做 | ✅ 已完成 |
| 5.0 | 定时 Agent | 定时巡检已完成 ✅；剩余：价格监控、销量预警 | ⭐⭐⭐ 部分完成 |
| 5.1 | 可视化工作流 | 用户自己拖拽搭建工作流（对标扣子） | ⭐⭐⭐⭐ 未做 |
| 6.0 | 多 Agent 协作 | 选品 Agent + 运营 Agent + 客服 Agent 分工 | ⭐⭐⭐⭐ 未做 |
