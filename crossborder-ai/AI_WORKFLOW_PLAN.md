## 一、当前 AI 能力现状

| 能力 | 实现方式 | 现状评价 |
|------|---------|---------|
| Listing 生成 | DeepSeek → 标题/描述/卖点/SEO | ✅ 可用，但用户需要手动逐条操作 |

## 二、AI 工作流优化方向（按优先级）

### 🔴 方向一：AI Agent 升级为"持久化工作流"

**现状问题：**
- Agent 每次对话独立，没有上下文记忆
- 执行完就结束，结果不保存
- 不能继续上次的对话

**优化方案：**

```
用户：帮我抓取这个商品 → Agent 执行 → 结果存数据库
用户：继续，生成 Amazon Listing → Agent 读取上一步的商品 → 生成
用户：然后发布到 Shopify → Agent 读取上一步的 Listing → 发布
```

**改动量：** ⭐⭐ 中
- 后端：建 `conversations` 表存对话历史，Agent 读取上下文
- 前端：Agent 页面已有聊天 UI，只需接入持久化

---

### 🔴 方向二：AI 工作流模板（Playbook）

**现状问题：**
- 用户每次都要说一遍"帮我抓取这个，生成 Listing，再发布"
- 没有预设的自动化流程

**优化方案：**

创建预设工作流模板，用户一键执行：

| 模板名称 | 自动执行步骤 |
|---------|------------|
| **1688 → Amazon 上架** | 抓取 → 翻译英文 → 生成 Listing → 合规审查 → 创建商品 |
| **1688 → Shopify 上架** | 抓取 → 生成描述 → 生成主图 → 发布到 Shopify |
| **批量利润分析** | 读取 CSV → 逐条计算利润 → 生成对比报表 |
| **自有商品上架** | CSV 导入 → 批量生成 Listing → 批量发布 |

**改动量：** ⭐⭐⭐ 中高
- 后端：定义工作流模板引擎，支持预设 + 自定义
- 前端：工作流模板市场/列表页，一键执行

---

### 🟡 方向三：AI 批量处理管道

**现状问题：**
- 批量任务（F4）目前只是 CSV 导入 → 创建商品，没有 AI 环节
- 不能批量抓取 + 批量生成 + 批量发布

**优化方案：**

```
上传 CSV（100 条商品）
  → AI 逐条抓取 1688 信息（可选）
  → AI 批量生成 Listing（并发 5 条）
  → AI 批量翻译
  → 批量合规审查
  → 批量发布到 Shopify
  → 生成执行报告
```

**改动量：** ⭐⭐⭐ 中高
- 后端：Batch Job 状态机扩展，支持多阶段 AI 处理
- 前端：Batch 页面加进度展示、结果预览、下载报告

---

### 🟢 方向四：AI 数据分析助手

**现状问题：**
- Dashboard 只看商品数量，没有经营分析
- 卖家不知道哪些商品好卖、利润怎么样

**优化方案：**

- "帮我分析这周新增的商品，哪些值得重点推"
- "对比这批商品的利润率，给出定价建议"
- "这个类目的趋势怎么样"

用 AI 分析已有数据（商品、价格、销量），给出可执行的建议。

**改动量：** ⭐ 低
- 主要是 Prompt 设计 + 数据聚合查询，不需要新架构

---

### 🟢 方向五：AI 选品助手

**现状问题：**
- 卖家不知道在 1688 上卖什么好
- 选品靠经验和运气

**优化方案：**

```
用户：我想做宠物用品，帮我推荐
→ AI 搜索 1688 宠物类目热销品
→ 返回 Top 10 推荐 + 价格区间 + 竞争分析
→ 用户选一个 → 自动抓取 + 生成 Listing
```

**改动量：** ⭐⭐ 中
- 需要 1688 搜索接口（API 或爬虫）
- 需要 Prompt 设计 + 结果展示 UI

---

### ⚪ 方向六：AI 自动化规则引擎

**现状问题：**
- 所有操作都要手动触发
- 不能设置"当 XX 发生时，自动做 YY"

**优化方案：**

```
规则示例：
- "当 1688 商品降价超过 10%，通知我"
- "每天自动检查新订单，标记高风险退款"
- "当库存低于 10 件，自动生成采购单"
```

**改动量：** ⭐⭐⭐⭐ 高
- 需要定时任务 + 事件系统 + 规则引擎
- 适合后期做，不适合现在

---

## 三、建议实施顺序

```
第一周：方向一（Agent 持久化）+ 方向四（数据分析）
  → 用户价值高，改动量小，立即见效

第二周：方向二（工作流模板）
  → 核心差异化功能，竞品没有

第三周：方向三（批量 AI 管道）
  → 配合方向二，规模化

后期：方向五（选品）+ 方向六（规则引擎）
  → 需要更多外部数据源
```
