## 一、前提条件

测试前需要满足：

| 条件 | 说明 |
|------|------|
| **登录平台** | 生产：`https://veyaship.com`（域名未备案则用 `https://47.116.138.61`）或本地开发环境 |
| **套餐要求** | AI 助手（agent）需要 **Standard 及以上** 套餐 |
| **白名单** | 测试账号 `admin@veyaship.com`、`test@veyaship.com` 不受套餐限制 |
| **积分** | 每次 Agent 运行消耗 1 积分（预设工作流 2 积分），不足会提示 |

**套餐限制说明**（`backend/app/core/access_control.py`）：

| 功能 | 可用套餐 |
|------|---------|
| AI 品类分析（category_analysis） | free / standard / professional |
| AI 智能助手（agent） | **standard / professional** |
| Shopify 发布 | standard / professional |
| AI 图片生成 | professional |

> 免费账号测试 Agent 会提示"AI 智能助手仅限 Standard 及以上套餐使用"。两种解决方式：
> 1. 使用白名单测试账号：`admin@veyaship.com` / `test@veyaship.com`
> 2. 联系管理员把账号邮箱加入白名单（`access_control.add_whitelist(email)`）

## 二、进入方式

1. 登录后，点击左侧边栏 **「AI 助手」**（路径 `/app/agent`）
2. 页面底部是对话输入框，支持自然语言指令
3. 页面有快捷入口按钮：**抓取 1688 / 生成 Listing / 计算利润 / 合规检查**，点一下自动填入对应指令

## 三、测试用例（由易到难）

### 1. 整店巡检（无需外部依赖）⭐ 最推荐先测

| 项 | 内容 |
|----|------|
| 输入 | `检查一下我的店铺` 或 `整店巡检` |
| 依赖 | 无（只用你店铺已有的商品数据） |
| 预期 | 列出所有商品，标出缺标题 / 缺价格 / 缺链接的问题项，返回统计摘要 |
| 验证 | 回复含"共 X 个商品，Y 个有问题，Z 个正常"；有问题的商品在结果里列出 |

> 联动验证：巡检结果会写入 `store_check_logs` 表，看板「整店巡检」区块可查历史；每天凌晨 2:30 还会自动巡检。

### 2. AI 品类分析（DeepSeek，平台已配置）

| 项 | 内容 |
|----|------|
| 输入 | `蓝牙耳机能不能做` 或 `分析下宠物用品类目` |
| 依赖 | DeepSeek API（平台配置，用户无感知） |
| 预期 | 输出 Markdown 市场分析报告：市场概览、价格分布、竞争格局、用户痛点、利润模型、选品建议 |
| 验证 | 回复有结构化标题和小标题，包含具体数字 |

### 3. 利润计算（无需外部依赖）

| 项 | 内容 |
|----|------|
| 输入 | `售价$19.99，成本¥30，运费¥15，帮我算净利` |
| 依赖 | 无 |
| 预期 | 算出净利润和利润率，含各项成本明细 |
| 验证 | 结果有具体数字和计算过程 |

### 4. AI 选品决策（DeepSeek）

| 项 | 内容 |
|----|------|
| 输入 | `我想做宠物用品，帮我选品` |
| 依赖 | DeepSeek |
| 预期 | 推荐值得做的商品 + 价格区间 + 竞争分析 + 利润估算 |
| 验证 | 返回 Top 推荐列表，每条有理由和预估利润 |

### 5. 1688 抓取 + 生成 Listing（需 Onebound）

| 项 | 内容 |
|----|------|
| 输入 | `帮我抓取 https://detail.1688.com/offer/xxx 并生成 Amazon Listing` |
| 依赖 | **Onebound API Key**（设置页配置）+ DeepSeek |
| 预期 | 抓取商品信息 → 自动生成标题/描述/卖点/SEO |
| 验证 | 生成的 Listing 基于抓取到的真实商品数据 |

### 6. 完整上架流程（需 Onebound + Shopify 授权）

| 项 | 内容 |
|----|------|
| 输入 | `把 https://detail.1688.com/offer/xxx 上架到我的 Shopify` |
| 依赖 | Onebound + DeepSeek + Shopify OAuth 授权 |
| 预期 | 抓取 → 翻译 → 生成 Listing → 合规检查 → 自动修复 → 发布到 Shopify |
| 验证 | 执行步骤按顺序完成，最后一步发布成功 |

## 四、闭环能力测试（验证 Agent 是否真闭环）

> **闭环 = 你只说一个目标，Agent 自己拆解成多步执行完；指令化 = 你说一句，它做一个动作，你得一步步指挥。**

### 测试方法

给 Agent 一个「端到端目标」（一句话），看它是否自动执行一串动作：
- 只回一句、只做一个动作 → 还是指令化
- 列出并执行 4-5 个步骤、把结果串起来 → **闭环 ✅**

### 推荐测试输入

| 输入（粘贴到对话框） | 预期自动执行步骤 | 依赖 |
|--------------------|-----------------|------|
| `把 https://detail.1688.com/offer/xxx 这个商品上架到我的 Shopify` | 抓取 → 翻译 → 生成 Listing → 合规检查 → 发布（5 步串起来） | Onebound + DeepSeek + Shopify |
| `帮我分析这个 1688 链接能不能做，能做就生成 Amazon Listing：https://detail.1688.com/offer/xxx` | 抓取 → 算利润 → 判断能不能做 → 生成 Listing | Onebound + DeepSeek |
| `检查这段商品描述有没有违禁词，有就修复：...（贴带敏感词的文案）` | 检查 → 发现违禁词 → 自动修复 → 返回干净版本（4.2 self-reflection） | DeepSeek |
| `检查一下我的店铺` | 整店巡检 → 列出问题商品 → 看板同步历史 | 无 |

### 对比：指令化 vs 闭环

| 旧方式（指令化，说 5 句） | 新方式（闭环，说 1 句） |
|--------------------------|------------------------|
| "抓取这个商品" | **"把这款商品上架到 Shopify"** |
| "翻译成英文" | ↕ Agent 自动执行 |
| "生成 Listing" | 抓取 → 翻译 → 生成 → 合规 → 发布 |
| "检查合规" | |
| "发布" | |

### 如何确认闭环成功

Agent 执行完会显示**步骤列表（steps）**，数一下步骤数：
- **1 个步骤** → 还是指令化
- **4-5 个步骤且结果串起来** → 闭环 ✅

## 六、注意事项

1. **对话持久化**：Agent 会自动保存对话历史，可继续上一轮说"继续上一步"
2. **积分消耗**：`/agent/run` 扣 1 积分，`/agent/workflow` 扣 2 积分
3. **外部依赖失败**：1688 抓取/上架依赖 Onebound API Key，未配置会提示失败；DeepSeek 为平台级配置，用户无感知
4. **合规检查**为"正则 + AI"双重检测，Agent 发现违禁词会自动走修复流程（4.2 self-reflection）
5. **接口地址**（供 API 直接调用）：
   - `POST /api/v1/agent/run` — 自然语言指令
   - `POST /api/v1/agent/workflow` — 预设工作流（参数：workflow、url、platform、language）
   - `GET /api/v1/agent/workflows` — 工作流列表
   - `GET /api/v1/agent/conversations` — 对话历史
