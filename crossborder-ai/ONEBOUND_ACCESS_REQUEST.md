# Onebound 接口开通需求说明

> 用途：向 Onebound 客服申请开通 1688 数据接口权限时，一次性说清需求
> 更新时间：2026-08-05
> 背景：当前平台（VeyaShip）的 1688 商品抓取功能，**全部依赖且仅依赖 Onebound 的 1 个接口**：`1688.item_get`（商品详情）

---

## 一、给客服的开通话术（可直接复制发送）

> 你好，我这边需要开通 **1688 商品详情接口 `1688.item_get`** 的调用权限，用于跨境电商平台的商品抓取功能。请帮忙开通并确认可用，谢谢。
>
> **接口**：`1688.item_get`（商品详情 API）
> **调用方式**：GET，参数 `key` / `secret` / `num_iid`
> **需要返回字段**：商品标题、主图、价格（含阶梯/批量价）、销量（近 30 天）、店铺名称
>
> 我们当前只需要这一个接口，无需搜索、商家信息等其他接口。请确认：
> 1. 该接口权限是否已开通、key/secret 是否可直接调用
> 2. 配额/套餐是否符合以下用量预估（见第三部分）
> 3. 如需要补充申请材料，请告知

---

## 二、技术参数（给客服/内部核对）

| 项 | 值 |
|----|----|
| **接口名** | `1688.item_get`（商品详情） |
| **请求地址** | `https://api-gw.onebound.cn/1688/item_get` |
| **请求方法** | GET |
| **请求参数** | `key`（API Key）、`secret`（API Secret）、`num_iid`（1688 商品 ID） |
| **成功判断** | 返回 JSON 中 `code == 0` |

**当前平台实际用到的返回字段**（代码中逐一读取）：

| 字段 | 代码读取 | 用途 |
|------|----------|------|
| 标题 | `data.title` | 商品标题展示、选品决策、生成 Listing |
| 主图 | `data.pic_url` / `data.main_pic` | 商品图片展示 |
| 价格 | `data.price` / `data.batch_price` | 采购价、利润计算、选品分析 |
| 销量 | `data.sales` / `data.sales_30day` | 近 30 天销量，市场热度判断 |
| 店铺名 | `data.shop_name` / `data.nick` | 供应商识别 |

> 说明：`num_iid` 从用户粘贴的 1688 链接提取（`https://detail.1688.com/offer/{商品ID}.html`）。

---

## 三、用量预估（供选套餐参考）

- **当前规模**：中小型卖家工具，抓取为低频操作（每次抓取扣 1 积分）
- **估算用量**：约 **50 ~ 200 次/天**（峰值不超过 500 次/天）
- **建议**：基础套餐即可，无需高级扩容；若后续上线批量抓取/整店巡检用到更多商品，再升级

---

## 四、常见问题（提前想清楚）

1. **为什么只需要一个接口？**
   - 平台代码所有抓取路径（商品页、选品分析、Agent 工具、竞品分析）最终都调用同一个 `scrape_1688()` → `item_get`。当前没有用到搜索、商家信息等其他接口。

2. **如果客服坚持要开多个接口怎么办？**
   - 说明当前仅 `item_get` 即满足业务，其余接口后续需要时再申请；**不要为暂时用不到的接口付费/开权限**。

3. **如果客服问接口配额上限？**
   - 按第三部分估算回复；重点确认调用不被限流。

4. **后续可能需要的接口（仅记录，暂不申请）**
   - `1688.item_search`（按关键词搜索）——未来选品搜索功能
   - `1688.seller_info` / `1688.shop_info`（店铺/商家信息）——未来供应商资质展示

---

## 五、平台侧配置入口（开通后怎么接入）

1. 登录平台 → **设置页 → 爬虫配置**
2. 填入 Onebound 下发的 `API Key` + `API Secret`
3. 保存后即可在商品页 / 选品分析 / AI 助手中使用 1688 抓取

> 对应代码：`backend/app/services/scraper.py` 的 `_try_onebound_api()`；配置存于 `system_config` 表（`onebound_api_key` / `onebound_api_secret`）
