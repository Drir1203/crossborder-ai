# 定位对比：Listing 生成器 vs AI 选品决策引擎

> 同一个技术栈，两个不同的说故事方式
> 2026-07-28

---

## 一、核心定位对比

| 维度 | 当前：Listing 生成器 | 目标：AI 选品决策引擎 |
|------|---------------------|---------------------|
| **一句话描述** | AI 自动生成商品 Listing | AI 帮你做跨境选品决策 |
| **用户价值** | 省掉写标题描述的时间 | 帮卖家判断"卖什么能赚钱" |
| **付费意愿** | "省时间"——愿意付但不多 | "帮赚钱"——愿意付更多 |
| **技术壁垒** | 低——调 API 就能做 | 中——数据 + 推理 + 多工具整合 |
| **TAM 故事** | Listing 工具市场 ~¥1 亿 | 选品决策市场 ~¥50 亿 |
| **融资吸引力** | ❌ 太窄 | ✅ 故事好讲 |

---

## 二、功能对比

| 功能 | 当前（Listing 生成器） | 目标（选品决策引擎） | 改动量 |
|------|---------------------|-------------------|--------|
| **1688 抓取** | ✅ 抓取商品详情 | ✅ 同上 + 批量抓取同类目商品 | ⚠️ 小 |
| **AI 生成 Listing** | ✅ 核心功能 | ✅ 保留，作为选品后的下一步 | ❌ 无 |
| **利润计算** | ✅ 手动输入算利润 | ✅ 自动从 1688+Amazon 数据算利润 | ⚠️ 小 |
| **竞品分析** | ⚠️ 手动输入竞品链接 | ✅ 自动搜索分析 Top 竞品 | ⭐ 中 |
| **AI 选品建议** | ❌ 没有 | ✅ 输入品类 → AI 出选品报告 | ⭐ 中 |
| **关键词分析** | ❌ 没有 | ✅ 分析品类关键词趋势 | ⭐⭐ 大 |
| **趋势预测** | ❌ 没有 | ✅ 基于历史数据预测品类走向 | ⭐⭐⭐ 大 |
| **Shopify 发布** | ✅ 有 | ✅ 保留 | ❌ 无 |
| **合规审查** | ✅ 有 | ✅ 保留 | ❌ 无 |
| **AI 智能助手** | ⚠️ 执行简单指令 | ✅ 执行复杂选品任务 | ⭐ 中 |

## 三、用户画像对比

### 当前用户
```
类型：1688 拿货卖家、小卖家
痛点：写英文 Listing 太慢、不会翻译
决策：¥79/月，省时间
规模：个人卖家为主
客单价：¥79/月
```

### 目标用户
```
类型：所有跨境卖家（含中大型）
痛点：不知道卖什么能赚钱、选品靠猜
决策：¥199-499/月，帮赚钱
规模：个人到小团队
客单价：¥199-499/月
```

### 用户场景对比

| 场景 | 当前 | 目标 |
|------|------|------|
| 早上到公司 | 打开 Dashboard 看商品数 | 打开选品看板看品类趋势 |
| 看到 1688 一个商品 | 粘贴链接 → 生成 Listing | 先分析这个品类利润空间 → 再决定是否上架 |
| 想开拓新品类 | ❌ 不知道怎么选 | 输入"宠物用品"→ AI 出报告 |
| 判断能不能做 | 手动算利润 | AI 自动算 + 竞品数据对比 |

## 四、改动点（代码层面）

### 需要新增

| 模块 | 改动量 | 说明 |
|------|--------|------|
| **品类分析 API** | ⭐⭐ 中 | `GET /api/v1/analytics/category?keyword=蓝牙耳机` |
| **AI 选品报告生成** | ⭐⭐ 中 | 调用 DeepSeek 分析多数据源出报告 |
| **批量类目抓取** | ⭐ 小 | 1688 搜索接口 + Amazon 搜索接口 |
| **数据缓存层** | ⭐⭐ 中 | 避免重复抓取，每日更新一次 |
| **选品报告前端** | ⭐ 小 | 展示报告结果的页面 |

### 需要修改

| 模块 | 改动 | 说明 |
|------|------|------|
| **Landing Page** | 重新写文案 | 从"生成 Listing"→"帮你选品" |
| **Dashboard** | 加选品看板 | 品类趋势、推荐机会 |
| **Agent** | 加选品任务 | "帮我分析蓝牙耳机能不能做" |
| **定价** | 加选品套餐 | ¥199/月（含报告 + 数据分析） |

### 不需要改的

- ✅ AI 生成 Listing 功能（保留）
- ✅ Shopify 发布（保留）
- ✅ 合规审查（保留）
- ✅ 利润计算（优化数据源即可）
- ✅ 用户系统、支付、套餐限制（全部保留）

## 五、故事线对比（融资用）

### 现在的故事
```
我们是 AI Listing 生成工具。
卖家粘贴链接，我们自动生成标题描述。
----------
投资人反应：然后呢？这有什么壁垒？
```

### 新的故事
```
我们是 AI 跨境选品决策引擎。
卖家说"我想做蓝牙耳机"，我们自动分析
Amazon 市场数据、1688 供货、利润空间、竞争格局，
告诉他"能做，建议切入 $25-40 价位，月利润约 ¥3 万"。
----------
投资人反应：数据哪来的？准确度多少？有多少用户了？
（虽然也会追问，但至少愿意继续聊）
```
